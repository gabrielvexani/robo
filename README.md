# Campeonato de Robôs

Projeto desenvolvido em Java para a disciplina de Programação Orientada a Objetos (POO).

## Sobre o projeto

O projeto consiste em um sistema de campeonato de robôs de combate. 
O programa funciona pelo terminal e permite cadastrar robôs, visualizar os robôs cadastrados e realizar combates entre eles.

## Funcionalidades

Atualmente o projeto possui:

- Cadastro de robôs
- Listagem dos robôs cadastrados
- Realização de combates
- Sistema de energia
- Sistema de ataque e defesa
- Contagem de vitórias, derrotas e pontos
- Definição de quem começa o combate
- Combate com até 5 rodadas
